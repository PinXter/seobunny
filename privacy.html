SEOBunny - Privacy Policy

Last updated: July 2026

SEOBunny is a browser extension for checking the on-page SEO of websites. This policy explains what data the extension handles, where it is stored and when it may be sent to a third-party AI provider.

What the developer collects

Nothing. SEOBunny has no accounts, analytics, telemetry or advertising. The developer does not receive or have access to data handled by the extension.

Browser storage

Preferences are stored using Chrome extension storage and may sync through your Chrome profile when browser sync is enabled. Scan results and optional AI API keys are stored in local extension storage. The developer does not receive or have access to this data.

  • Interface preferences, including language, theme and highlight colors
  • Scan settings and opening mode
  • Recent scan results and comparison data
  • Your AI provider API key, if you choose to add one

You can clear stored data by resetting SEOBunny from its Settings page. Uninstalling the extension removes its locally stored extension data. Preferences synced through Chrome are managed by your Chrome profile.

Website content

When you scan a page or website, SEOBunny reads page content such as titles, meta tags, headings, links and image alt texts to create the requested SEO report. Whole-site scans fetch pages from the website selected by the user. This processing takes place inside the browser.

Optional AI feature

If you connect your own API key and start AI generation, relevant content from the selected pages and your API key are sent directly from your browser to the provider you selected: Anthropic, OpenAI, Google or xAI. Requests are sent over HTTPS and only after you explicitly start the feature.

The SEOBunny developer is not part of this exchange and cannot see the request or response. The selected provider processes the request under its own terms and privacy policy.

Permissions

SEOBunny requests access to websites so it can scan pages selected by the user and display the optional highlight overlay. The side panel permission allows the interface to remain open while the user changes tabs. SEOBunny does not monitor browsing activity or send website content to the developer.

Data use

Data handled by SEOBunny is used only to provide its page scanning, site auditing, highlighting, exporting and optional AI drafting features. It is not sold, used for advertising or transferred for unrelated purposes.
